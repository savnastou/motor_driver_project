# Dual Motor Driver Project

Project in the scope of ECE NTUA course "Microelectronics and Packaging Techniques".

*Team Members*: Dionysios-Rafail Defteraios, Savvina Nastou

Implemented the circuit schematic, 2D PCB board schematic and 3D model of a dual motor driver module with a heat sink using the *Autodesk Fusion 360* platform. Additionally, performed thermal analysis of the IC and its attached heat sink using *Simscale*.

Project Fusion url: https://a360.co/4t3ZZwr
